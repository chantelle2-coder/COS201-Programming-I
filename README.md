# COS201-Programming-I
This repository contains 3 java programs developed for the COS201 assignment
# Java Programming Assignment

This project contains three Java programs.

## 1. SimpleCalculator
This program accepts two numbers and calculates their sum,
difference, product, and quotient.

## 2. AverageCalculator
This program accepts a student's name and three scores.
It calculates the total and average score.

## 3. ItemCost
This program accepts an item name, quantity, and price per item.
It calculates the total cost.
